# odoo-favorite-modules
Easily add any Odoo module as a favorite and filter favorite apps

I created this module while doing Odoo practice modules, as I often needed to search for app names repeatedly for upgrades. To make the process faster, I added a "Favorites" feature.

**[Get it on the Odoo Apps Store](https://apps.odoo.com/apps/modules/18.0/odoo-favorite-modules)**
<br><br>


## Favorite Modules Manager
### Easily mark any module as your favorite and access it instantly

* *Easily add any Odoo module to your favorites using the toggle button in each module’s kanban menu 」*
* *Integrated "Favorite Apps" filter in the menu bar for instant access 」*
* *Save time searching for frequently used apps 」*

Make your work easier by saving and finding modules in seconds.
